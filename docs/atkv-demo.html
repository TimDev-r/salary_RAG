Which year’s salary table is this?

Retrieval over the Austrian IT collective agreement and related labour law, answering with a citation to the exact paragraph and page.

version-scoped RAG salary_RAG measured results

The problem: the 2025 and 2026 agreements are about 95% identical text, on the same page, in the same layout. Only the numbers move. Ask an embedding model for “the ST1 minimum salary” and it returns the wrong year confidently, because the two paragraphs are near-indistinguishable by meaning. The fix is not a better model — it is a hard filter on valid_from applied before ranking, which is the same mechanism enterprise search needs for access control.
